# 가상 인트라넷

경연 시연용으로 만든 가짜 그룹웨어입니다. 화면(`index.html`)과 서버(`server.py`)로 이루어져 있습니다.

서버가 하는 일은 세 가지입니다.

1. 지은이 정리한 `data/` 의 규정·서식을 인트라넷 **자료실**에 올려 둡니다.
2. 서무비서(`app/`)가 그 규정·서식을 읽어 갈 수 있게 **연동 API**를 엽니다.
3. 서무비서가 만든 기안을 받아 **전자결재함**에 넣습니다.

실제 결재망으로는 아무것도 나가지 않습니다.

## 켜기

윈도우는 `실행.bat` 을 두 번 누르면 됩니다. 그 밖의 환경은 아래와 같습니다.

```bash
pip install -r requirements.txt
python server.py
```

켜지면 <http://127.0.0.1:8100> 입니다. 포트는 파트 사이의 약속대로 **8100**이고, 서무비서는 8000을 씁니다.

## 같이 켜는 순서

1. 이 폴더에서 인트라넷을 켭니다. 8100번입니다.
2. `app/` 에서 서무비서를 켭니다. 8000번입니다.
3. 서무비서에게 "세종 출장 가려는데" 처럼 물어보면, 규정을 인트라넷에서 읽고 기안을 만들어 인트라넷 **임시보관문서**에 올려 둡니다.
4. 인트라넷 화면에서 내용을 확인하고 **사람이 상신**을 누릅니다.

서무비서는 스스로 상신하지 않습니다. 올려 두는 데까지만 하고 멈춥니다.

## 로그인

실제 그룹웨어처럼 아이디·비밀번호로 들어갑니다. 연동 API가 없는 기관에서는 서무비서가
사람과 똑같이 로그인해서 읽고 쓰기 때문에, 그 길을 시연하려면 로그인 화면이 필요합니다.

| 아이디 | 사람 | 직급 |
|---|---|---|
| `u-kim` | 김서무 | 5급 직원 (담당자) |
| `u-park` | 박차장 | 3급 차장 (담당자) |
| `u-lee` | 이팀장 | 2급 부장 (결재자) |
| `u-choi` | 최센터장 | 1급 센터장 (결재자) |
| `u-ceo` | 대표이사 | 임원 |

비밀번호는 모두 `demo1234` 입니다. 시연용 가상 계정이라 코드에 적혀 있습니다.
세션은 서버를 다시 켜면 풀립니다.

연동 API는 로그인과 무관하게 `Authorization: Bearer <키>` 로 그대로 씁니다.

## 연동 API

서무비서가 쓰는 창구입니다. 주소를 바꾸면 알려 주세요.

| 방법 | 주소 | 하는 일 |
|---|---|---|
| GET | `/api/v1/regulations` | 규정·지침·매뉴얼 목록. `org_id`, `category` 로 거를 수 있음 |
| GET | `/api/v1/regulations/{문서코드}/file` | 규정 전문 내려받기 |
| GET | `/api/v1/templates/forms` | 서식 목록. `org_id`, `category` 로 거를 수 있음 |
| GET | `/api/v1/templates/{서식코드}/file` | 서식 전문 내려받기 |
| POST | `/api/v1/documents/draft` | 기안 올리기 (임시저장). 첨부가 있으면 multipart |
| POST | `/api/v1/documents/{문서번호}/submit` | 상신 (사람이 누를 때만) |
| GET | `/api/v1/documents/{문서번호}/status` | 기안 상태 조회 |
| GET | `/api/v1/documents` | 들어온 기안 전체 |
| GET | `/api/v1/orgs`, `/api/v1/orgs/{id}` | 기관 정보 |
| GET | `/api/files/{파일id}` | 첨부 내려받기 (화면이 씁니다) |
| GET | `/api/health` | 살아 있는지 확인 |

인증은 `Authorization: Bearer <키>` 로 받습니다. 시연에서는 아무 값이나 됩니다.

### 기안 올리기 본문

```json
{
  "title":    "(11.5.) 세종 출장 신청",
  "content":  "출장·여비에 대하여 다음과 같이 요청합니다. ...",
  "category": "F02",
  "org_id":   "bwyf",
  "approvers": ["담당", "팀장"],
  "state":    "draft"
}
```

`state` 가 `draft` 면 **임시보관문서**에, `submitted` 면 **상신문서**에 들어갑니다. 서무비서는 언제나 `draft` 로 보냅니다.

돌려주는 값입니다.

```json
{"ok": true, "data": {"doc_no": "BWYF-20261105-0001", "state": "draft",
                      "folder": "임시보관문서", "created_at": "..."}}
```

## 자료가 쌓이는 곳

| 경로 | 내용 |
|---|---|
| `../data/` | 규정·서식 원본. 서버는 **읽기만** 합니다 |
| `운영자료/state.json` | 들어온 기안 |
| `운영자료/첨부/` | 기안에 붙은 파일 |

`운영자료/` 를 지우면 기안이 모두 사라지고 처음 상태로 돌아갑니다. 시연을 다시 할 때 쓰면 됩니다.

## 실제 그룹웨어에 붙일 때

서무비서는 이 API 모양으로만 말을 겁니다. 기관마다 전자결재 시스템이 다르므로, 바꿔 끼우는 자리는 `app/app/intranet.py` 한 곳입니다. 자세한 내용은 `app/INTRANET_INTEGRATION_GUIDE.md` 를 보세요.
