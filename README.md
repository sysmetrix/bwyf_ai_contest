# bwyf_ai_contest

부천여성청소년재단(BWYF) 팀의 AI 경진대회 출품작 **서무비서** 작업 레포입니다. (공개)

> 처음 오셨다면 [시작하기.md](시작하기.md)와 [docs/협업가이드.md](docs/협업가이드.md)부터 읽어 주세요.
> AI 도구는 [AGENTS.md](AGENTS.md)의 규칙을 따릅니다.

## 실행

Python 3.10 이상이 필요합니다. **서무비서 하나만 켜면 인트라넷도 같이 열립니다.**
(연동약속 v0.2)

### 윈도우

`app\설치.bat` 을 두 번 누르면 됩니다. 처음 한 번만 알아서 설치합니다.
설치할 때 **"Add Python to PATH"** 에 꼭 체크하세요. 다음부터는 `app\실행.bat` 입니다.
끌 때는 창에서 Ctrl+C 를 누르거나 `app\끄기.bat` 을 실행합니다.

### 맥·리눅스

```bash
cd app && pip install -r requirements.txt && python run.py
```

### 주소

- 서무비서: <http://localhost:8000>
- 가상 인트라넷: <http://localhost:8000/intranet/>

### 다른 PC에서도 보여 주려면

기본은 내 PC에서만 열립니다. 같은 사무실 망의 다른 PC에서도 열어 보게 하려면
`app\같은망에서 보여주기.bat` 을 대신 실행하세요. 창에 `http://192.168.0.x:8000` 처럼
주소가 뜹니다. 그 주소를 알려 주면 됩니다. 시연이 끝나면 창을 닫아 주세요.

### 둘러보는 순서

1. 서무비서에게 말을 겁니다. 예: **"모레 세종으로 출장 가는데 기안 올려줘"**
2. 답에 붙은 **기안 올리기**를 누르면 확인 화면이 나옵니다. 제목·본문·장소·기간·결재선을
   고칠 수 있고, 영수증을 끌어다 놓을 수 있습니다.
3. 올리면 가상 결재함에 공문서 모양으로 들어갑니다. 서무비서는 상신하지 않습니다.
   사람이 인트라넷 화면에서 확인하고 누릅니다.
4. 담당자를 `최센터장`으로 바꾸면 서무비서가 결재할 문서를 먼저 브리핑합니다.
   같은 출장이라도 **직원이 가면 실장 전결, 센터장이 가면 대표이사 결재**입니다.

### AI 답변에 대하여

규정을 찾아 주는 것까지는 AI 없이도 됩니다. 문장을 다듬는 데만 이 PC의 모델을 씁니다.
모델이 없으면 규칙으로 만든 문장이 그대로 나오고, 기능은 모두 동작합니다.
모델을 쓰려면 [Ollama](https://ollama.com) 를 설치하고 `ollama pull gemma3:4b` 하면 됩니다.
