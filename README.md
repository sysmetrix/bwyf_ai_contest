> 처음 오셨다면 [시작하기.md](시작하기.md)와 [docs/협업가이드.md](docs/협업가이드.md)부터 읽어 주세요.

## 실행

서무비서와 가상 인트라넷 **두 개를 함께** 켭니다. 포트는 서무비서 8000, 인트라넷 8100입니다.

### 윈도우

창 두 개를 띄우면 됩니다. 파일을 두 번 누르면 처음 한 번만 알아서 설치합니다.

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `intranet\실행.bat` | 가상 인트라넷을 켭니다 (8100) |
| 2 | `app\설치.bat` | 서무비서를 설치하고 켭니다 (8000). 다음부터는 `app\실행.bat` |

Python 3.10 이상이 필요합니다. 없으면 설치 파일이 받는 곳을 열어 줍니다.
설치할 때 **"Add Python to PATH"** 에 꼭 체크하세요.

끌 때는 각 창에서 Ctrl+C 를 누르거나 `끄기.bat` 을 실행합니다.

### 맥·리눅스

```bash
cd intranet && pip install -r requirements.txt && python server.py   # 창 1
cd app      && pip install -r requirements.txt && python run.py      # 창 2
```

### 다른 PC에서도 보여 주려면

기본은 내 PC에서만 열립니다. 같은 사무실 망의 다른 PC에서도 열어 보게 하려면
`같은망에서 보여주기.bat` 을 대신 실행하세요. 창에 `http://192.168.0.x:8100` 처럼
주소가 뜹니다. 그 주소를 알려 주면 됩니다. 시연이 끝나면 창을 닫아 주세요.

### 둘러보는 순서

1. <http://127.0.0.1:8100> 에서 인트라넷에 로그인합니다.
   아이디 `u-kim`(직원) 또는 `u-choi`(센터장), 비밀번호는 둘 다 `demo1234` 입니다.
   게시판 › 자료실에 규정과 서식이 올라와 있습니다.
2. <http://127.0.0.1:8000> 에서 서무비서에게 말을 겁니다.
   예: **"모레 세종으로 출장 가는데 기안 올려줘"**
3. 답에 붙은 **기안 올리기**를 누르면 확인 화면이 나옵니다. 제목·본문·장소·기간·결재선을
   고칠 수 있고, 영수증을 끌어다 놓을 수 있습니다.
4. 올리면 인트라넷 **전자결재 › 임시보관문서**에 공문서 모양으로 들어갑니다.
   서무비서는 상신하지 않습니다. 사람이 확인하고 누릅니다.
5. 담당자를 `최센터장`으로 바꾸면 서무비서가 결재할 문서를 먼저 브리핑합니다.
   같은 출장이라도 **직원이 가면 실장 전결, 센터장이 가면 대표이사 결재**입니다.

### AI 답변에 대하여

규정을 찾아 주는 것까지는 AI 없이도 됩니다. 문장을 다듬는 데만 이 PC의 모델을 씁니다.
모델이 없으면 규칙으로 만든 문장이 그대로 나오고, 기능은 모두 동작합니다.
모델을 쓰려면 [Ollama](https://ollama.com) 를 설치하고 `ollama pull gemma3:4b` 하면 됩니다.

### 시연을 처음부터 다시
