# bwyf_ai_contest

부천여성청소년재단(BWYF) 팀의 AI 경진대회 출품작 **서무비서** 작업 레포입니다. (공개)

> 처음 오셨다면 [시작하기.md](시작하기.md)와 [docs/협업가이드.md](docs/협업가이드.md)부터 읽어 주세요.
> AI 도구는 [AGENTS.md](AGENTS.md)의 규칙을 따릅니다.

## 실행

서비는 **화면에 떠 있는 위젯**으로 씁니다. 브라우저로 쓰지 않습니다.
켜면 화면 구석에 서비가 나타나고, 눌러서 말을 겁니다.
인트라넷은 서비가 자기 창으로 띄웁니다.

### 윈도우 — 파이썬 없이 바로 (권장)

파이썬도 위젯도 들어 있는 설치판을 받아 쓰면 아무것도 따로 깔 필요가 없습니다.

1. 저장소 위쪽 **Actions → 윈도우 설치판 만들기 → Run workflow** 를 누릅니다.
2. 끝나면 아래 **Artifacts** 에서 `서비_Windows설치판` 을 받습니다.
3. 압축을 풀고 `설치하기.bat` 을 두 번 누릅니다. 다음부터는 `서비 실행.bat` 입니다.

### 맥

`app` 폴더의 `설치.command` 를 두 번 누릅니다. 파이썬과 위젯을 함께 준비하고 켭니다.
다음부터는 바탕화면의 **서비** 또는 `서비 실행.command` 입니다.
끌 때는 `서비 끄기.command` 입니다.

Python 3.10 이상과 Node.js 가 필요합니다. 없으면 설치 파일이 받는 곳을 알려 줍니다.

### 이 PC에서 돌아갈까요 (윈도우 기준)

서비는 AI가 없어도 규정을 찾고 기안을 만듭니다. AI는 문장을 다듬는 데만 쓰고,
그것도 이 PC 안에서만 돕니다. 그래서 최소 사양이 낮습니다.

| | 운영체제 | 메모리 | 여유 공간 | CPU | 쓸 수 있는 것 |
|---|---|---|---|---|---|
| **최소** | Windows 10 64비트 | 4GB | 2GB | 2코어 | 규정 검색·기안 작성 등 **모든 기능** |
| **권장** | Windows 10/11 | 8GB | 10GB | 4코어 | + AI 문장 다듬기 (gemma3:4b, 3.3GB) |
| **넉넉** | Windows 11 | 16GB 이상 | 20GB | 8코어 | 큰 모델, 눈에 띄게 빠름 |

그래픽카드(NVIDIA 8GB 이상)가 있으면 AI 답이 몇 배 빨라집니다. 없어도 됩니다.

처음 켜면 서비가 **이 PC를 직접 점검해서** 무엇이 되고 무엇이 모자란지 알려 줍니다.
설정에서 언제든 다시 볼 수 있습니다.

### 처음 켤 때

처음 한 번만 설정 창이 뜹니다. 세 단계입니다.

1. **이 PC에서 돌아갈까요** — 사양을 점검해 보여 줍니다
2. **쓰고 계신 전자결재 시스템** — 주소와 계정을 넣으면 서비가 직접 들어가
   규정·서식·조직도를 읽고 기안 쓰는 법까지 익힙니다. 나중에 해도 됩니다
3. **끝** — 화면 구석의 서비에게 말을 걸면 됩니다

연결 방법은 둘 중에 고릅니다.

| 방법 | 넣는 것 | 쓰는 곳 |
|---|---|---|
| 연동 API | 주소 + 읽기 전용 키 | 기관이 API를 열어 주는 경우 (권장) |
| 아이디·비밀번호 | 주소 + 아이디 + 비밀번호 | API가 없는 그룹웨어 (크롬·엣지 필요) |

비밀번호는 설정 파일에 적지 않습니다. 윈도우 **자격 증명 관리자**에 맡깁니다.
연결하지 않아도 저장소의 `data/` 규정으로 그대로 쓸 수 있습니다.

### 둘러보는 순서

1. 서비에게 말을 겁니다. 예: **"모레 세종으로 출장 가는데 기안 올려줘"**
2. 답에 붙은 **기안 올리기** 를 누르면 확인 화면이 나옵니다. 제목·본문·장소·기간·결재선을
   고칠 수 있고, 영수증을 끌어다 놓을 수 있습니다.
3. 올리면 **인트라넷 창이 바로 떠서** 들어간 것을 보여 줍니다.
   서비는 상신하지 않습니다. 사람이 확인하고 누릅니다.
4. 작업내역을 열면 **다음: 출장 여비 정산** 처럼 이어서 할 일 버튼이 있습니다.
5. 담당자를 `최센터장` 으로 바꾸면 결재할 문서를 먼저 브리핑합니다.
   같은 출장이라도 **직원이 가면 실장 전결, 센터장이 가면 대표이사 결재**입니다.

### AI 답변에 대하여

규정을 찾아 주는 것까지는 AI 없이도 됩니다. 문장을 다듬는 데만 이 PC의 모델을 씁니다.
모델이 없으면 규칙으로 만든 문장이 그대로 나오고, 기능은 모두 동작합니다.
모델을 쓰려면 [Ollama](https://ollama.com) 를 설치하고 `ollama pull gemma3:4b` 하면 됩니다.
