# 서비 (서무비서, 범용 · 기관 설정형) — 프로토타입

어느 기관이든 **기관 프로필을 작성하고 규정 폴더를 넣으면 그 기관 전용으로 바뀌는 서무비서 '서비'**입니다.
2026 공공 AI 대전환 챌린지 세션 2, 지정과제 ② 서무비서 출품을 목표로 만든 프로토타입입니다.

> ⚠️ 포함된 규정·프로필·서식은 모두 **시연용 가상 데이터**입니다. 실제 기관 규정이 아닙니다.

## 주요 기능

| 화면 | 기능 |
| --- | --- |
| 서비(서무비서) | 담당자 선택 → "기한 지난 건·임박 건·최근 처리" 브리핑. 상황을 말하면(마이크 입력 가능) 업무 분류 → 처리 절차, 기한(날짜 계산), 전결권자, 필요 서류, 근거 조문, 다음 할 일 안내 → 서식 초안(.docx/.hwpx) 생성. 답변을 담당자 메일로 바로 받기(발신 전용) |
| 서식 보관함 | 업무별 서식(.docx/.hwpx) 확인·다운로드, 화면에서 바로 올려 교체, 서비 질문으로 바로 초안 요청 |
| 기관 프로필 | 규정 폴더에서 프로필 초안 자동 생성(근거 조문 표시) → 확인·수정 → 저장, 규정과 충돌하는 관행 메모 경고, 새 기관 등록(유형별 템플릿)·삭제(복구 가능), 규정 폴더 가져오기(원본 보호) |
| AI 모델 연결 | 연결을 원하는 만큼 추가·삭제, 역할별 모델 교체, 연결 테스트, 테스트 질문 세트로 모델별 정확도 비교 |
| 설정 | 담당자 프로필(이름·소속·메일) 관리, 메일 발신(SMTP) 연결 설정 |

## 설치와 실행

필요한 것: Python 3.10 이상

**가장 쉬운 방법**: `설치.bat`(Windows) 또는 `설치.sh`(macOS/Linux)를 더블클릭(또는 `./설치.sh`)하면 패키지 설치부터 실행까지 한 번에 됩니다.

처음 한 번 설치한 뒤에는 **`실행.bat`** 만 더블클릭하면 됩니다(브라우저가 자동으로 열립니다). 실행에 실패하면 창이 바로 닫히지 않고 이유(설치 안 됨, 포트 사용 중 등)를 보여 줍니다. `run.py`를 직접 더블클릭하지 말고 `실행.bat`을 쓰세요.

**직접 실행하려면**:
```bash
pip install -r requirements.txt
python run.py
```

브라우저에서 **http://localhost:8000** 을 엽니다. 처음 열면 **기관 → 담당자** 2단계 설정 화면이 뜨고, 끝나면 바로 질문할 수 있습니다. 설치 직후에는 AI 없이(규칙 기반) 모든 기능이 동작합니다.

## AI 모델 연결 (선택)

OpenAI 호환 API라면 어떤 모델이든 연결할 수 있습니다. Ollama 예시:

```bash
# 1) https://ollama.com 에서 Ollama 설치
ollama pull gemma3:4b          # 업무 분류용(작은 모델)
ollama pull exaone3.5:7.8b     # 안내 문장·프로필 보완용
```

2) 화면 상단 **AI 모델 연결**에서 역할마다 `ollama`를 고르고 모델 이름을 적은 뒤 **저장 → 연결 테스트**.
3) **모델 비교 테스트**에서 모델을 추가하고 실행하면 정확도 표가 나옵니다.

기본으로 `ollama`·`vllm`·`gov_ai` 3개 연결이 있지만, **새 연결 추가**로 OpenAI 등 원하는 OpenAI 호환 API를 이름·주소·키 환경변수만 적어 몇 개든 더 등록할 수 있습니다. 역할(업무 분류/안내 문장/프로필 보완)마다 서로 다른 연결을 골라 쓸 수 있어, 한 화면에서 여러 회사의 모델을 동시에 비교·운용할 수 있습니다.

기관 AI 공통기반 등 다른 서버는 `config.yaml`의 `base_url`을 바꾸고, API 키는 환경변수(예: `GOV_AI_API_KEY`)로 넣습니다. 키를 파일에 적지 마세요.

AI가 맡는 일과 규칙이 맡는 일을 나눴습니다. 모델을 바꿔도 기한·전결권자 같은 결과는 흔들리지 않습니다.

| 일 | 처리 |
| --- | --- |
| 말 이해(업무 분류·정보 추출) | AI (연결 없거나 실패 시 키워드 규칙) |
| 안내 문장 다듬기 | AI (근거 조문만 사용) / 없으면 정해진 문장 |
| 프로필 초안 빈칸 보완 | AI / 없으면 추출 규칙만 |
| 기한 계산, 전결권자 판정, 서식 채우기 | 규칙 (AI 불필요) |

## 새 기관 적용하기

1. **기관 프로필 → 새 기관 등록**: 기관 ID, 이름, 유형 템플릿(중앙부처형·지자체형·출연기관형)
2. **규정 폴더 가져오기**: 규정 파일이 있는 폴더 경로 입력 (md, txt, docx, hwpx, pdf). 구형 `.hwp`는 한글에서 HWPX나 PDF로 저장해 넣어 주세요.
3. **규정에서 AI 초안 만들기** → 값과 근거를 확인하고 **선택한 값 반영 → 프로필 저장**
4. 서식: 기관 서식(.docx 또는 .hwpx)의 빈칸에 `{{출장자}}`처럼 자리표시를 넣어, 화면 **서식 보관함 → 서식 올리기**로 바로 올리거나 `data/orgs/<기관>/forms/`에 직접 두면 초안이 채워집니다.

## 폴더 구조

```
app/            서버 코드
  llm.py        AI 연결부 (모델 교체는 여기만 관여)
  mailer.py     메일 발신부 (발신 전용, 받은 메일은 읽지 않음)
  understand.py 업무 분류·정보 추출
  rules.py      규정 저장소 (조문 단위 분할, 층별 검색)
  engine.py     안내 생성 (기한·전결·절차)
  forms.py      서식 초안 생성 (.docx/.hwpx)
  drafter.py    프로필 초안·충돌 점검
  main.py       API
web/            화면 (UI 디자인은 app.css와 각 HTML만 바꾸면 됨)
data/common/    공통 규정, 업무 정의(tasks.yaml), 테스트 질문(eval_set.yaml)
data/templates/ 기관 유형별 기본 프로필
data/orgs/      기관별 프로필·규정·서식
outputs/        생성된 서식 초안 (원본과 분리)
tests/          테스트 (가짜 AI 서버 포함)
```

규정은 **공통 규정 → 기관 규정 → 부서 보충(`rules/dept/`)** 세 층으로 관리하며, 가까운 층이 우선합니다.

## 원본 보호와 데이터 원칙

- 가져온 규정은 **복사본**만 처리하고 원본 폴더는 읽기만 합니다.
- 서식 초안은 `outputs/`에 새 파일로 만들고 원본 서식은 바꾸지 않습니다.
- 프로필을 저장하면 이전 버전이 `profile_history/`에 보관됩니다.
- 기관을 삭제해도 영구 삭제가 아니라 `data/orgs_deleted/`로 옮겨 보관합니다.
- 개발·시연에는 공개 규정과 가상 데이터만 사용합니다.

## 테스트

```bash
python -m pytest -q
```

AI 연결 경로는 `tests/fake_llm.py`(가짜 OpenAI 호환 서버)로 확인합니다.

## 업무 추가하기

`data/common/tasks.yaml`에 업무를 추가하면 모든 기관에 적용됩니다. 절차 문장에 `{값:키}`, `{용어:표준어}`, `{결재선}`을 넣으면 기관 프로필 값으로 바뀝니다.
