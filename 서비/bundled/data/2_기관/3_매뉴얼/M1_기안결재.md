# M1. 기안과 결재

## 1. 핵심 포인트

**결재 용어**

| 용어 | 뜻 |
|---|---|
| 검토 | 중간 결재자로서 의견을 쓰고, 문서를 고치거나 반려할 수 있음 |
| 협조 | 업무와 관련 있는 사람으로서 의견을 낼 수 있으나 문서를 고칠 수는 없음 |
| 결재 | 최종 결재권자로서 의견을 쓰고, 문서를 고치거나 반려할 수 있음 |
| 전결 | 대표이사가 사무의 일부를 부서장 등에게 위임하여 결재하게 하는 것 |
| 대결 | 원래 결재자가 결재할 수 없을 때 다른 사람이 대신 결재하는 것 |

**결재 순서**: 기안자 → 검토자·협조자 → 결재권자
- 하위 직급에서 상위 직급 순으로 지정한다.
- 같은 직급이면 소속 부서를 먼저, 타부서를 나중에 지정한다.
- 타부서의 같은 직급 여러 명에게 차례로 협조받을 때에도 소속 부서 → 타부서 순으로 지정한다.

| | 결재선 |
|---|---|
| 옳은 예 | 산울림청소년센터 대리 → (검토) 산울림청소년센터 차장 → (협조) 소사청소년센터 차장 → (검토) 산울림청소년센터 부장 → (전결) 산울림청소년센터장 |
| 틀린 예 | 산울림청소년센터 대리 → (검토) 산울림청소년센터 차장 → (검토) 산울림청소년센터 부장 → (협조) 소사청소년센터 차장 → (전결) 산울림청소년센터장 |

틀린 예는 상위 직급(부장) 뒤에 하위 직급(차장)의 협조가 와서 순서가 어긋났다.

**공문서 기본 양식**: 굴림체, 글씨 크기 12, 줄 간격 160%

**표기법**

| 항목 | 기준 | 예시 |
|---|---|---|
| 기본 | 한글(표준어), 검은색. 뜻을 분명히 하려면 한자·영문 병기 가능 | |
| 숫자 | 아라비아 숫자. 금액은 한글이나 한자 병기 가능 | 금113,560원(금일십일만삼천오백육십원) |
| 시간 | 24시간제. 시·분 글자를 빼고 쌍점(:)으로 구분 | 오후 3시 20분(×) → 15:20(○) / 오전 7시 9분(×) → 07:09(○) |
| 날짜 | 숫자. 연·월·일 글자를 빼고 온점(.)으로 구분 | 2026.11.05.(×) / 2026. 11. 05.(×) → 2026. 11. 5.(○) |

**가장 헷갈리는 것 3가지**
1. **접수 문서를 참조해 기안할 때**: 대외 접수 문서는 외부 기관명을 정확히 적는다. 대내 접수 문서는 부서명만 적는다.
   - 대외: 부천시 아동청소년과-100(2026. 6. 15.)호
   - 대내: 전략경영실-100(2026. 6. 15.)호
2. **결재가 끝난 문서에서 오류를 발견했을 때**
   - 문자: 해당 부분에 붉은 선을 긋고 작성자가 날인한 뒤, 그 오른쪽이나 위에 바르게 고쳐 적는다.
   - 두서금액(기안문에 적힌 지급금액): 고치거나 지울 수 없으므로 다시 상신한다.
   - 지출결의서의 금액·예산과목: 고치거나 지우거나 고쳐 쓸 수 없으므로 마이너스 지출결의서를 상신한 뒤 다시 상신한다.
3. **붙임 표기 "1부"와 "각 1부"**: 문서가 하나면 "1부", 성격이 다른 문서가 둘 이상이면 "각 1부"라고 쓴다.

## 3. 처리 절차

| 순서 | 할 일 | 기준 | 근거 |

| ② | 형식 확인 | A4, 여백(위 30 / 왼쪽 20 / 오른쪽·아래 15mm), 항목 기호 순서, 표기법, 끝 표시 | 사무 제6조~제13조 |
| ③ | 결재권자 찾기 | 전결표에서 해당 사무를 찾는다. 열거되지 않은 사무는 비슷한 전결사항에 준하고, 판단하기 어려우면 차상위 직위자 결재 | 세칙 별표, 책임 제5조③ |
| ④ | 결재선 지정 | 하위 → 상위, 같은 직급은 소속 부서 → 타부서 | 사무 제19조 |
| ⑤ | 협조 지정 | 다른 부서와 관련되면 협조. 회계 관련은 아래 4-2 표 참고 | 사무 제20조, 책임 제8조③ |
| ⑥ | 상신·결재 | 결재권자는 서명하고 결재일자를 표시. 전결·대결이면 결재란에 "전결"·"대결" 표시 | 책임 제7조②, 사무 제22조⑤ |
| ⑦ | 결재권자가 부재하면 | 차하위 직위자가 결재. 대결한 중요 문서는 나중에 결재권자에게 보고 | 책임 제6조, 사무 제22조②③ |

### 4-3. 공사·물품·용역 품의 결재선

대표이사 결재와 경영지원부 협조는 "품의" 단계에서만 한다. 계획이나 지급 단계에서는 하지 않는다.

| 추정금액 (부가세 포함) | 결재선 |
|---|---|
| 200만원 초과 550만원 이하 | ① 품의(담당자) → ② 검토·협조(중간 결재자, 경영지원부) → ③ 전결(부서장) |
| 550만원 초과 | ① 품의(담당자) → ② 검토·협조(중간 결재자, 경영지원부) → ③ 검토(부서장) → ④ 대표이사 결재 |

※ 전결표의 기준은 추정가격(부가세 별도) 500만원이다. 부가세를 포함하면 550만원이 되므로 실무에서는 550만원으로 판단한다.
※ 추정가격은 부가세를 뺀 금액이고, 추정금액은 추정가격에 부가세와 관급자재를 더한 금액이다.

## 6. 유의사항

- 중간 결재자의 이견 표시를 지우거나 문서를 다시 만들어 결재하지 않는다 (책임 제7조③).
- 협조자가 동의하지 않으면 사유를 밝히고 서명한다. 서명을 거부하거나 회송을 늦추면 안 된다. 협조가 안 된 사항은 결재권자가 정한다 (사무 제20조).
- 검토자나 협조자가 덧붙인 의견은 전결권자가 동의를 표시해야 효력이 있다. 전자결재에서는 의견란에 동의 여부를 밝힌다 (사무 제21조).
- 결재 과정에서 고친 사항은 고친 결재자 이상이 연대하여 책임진다 (사무 제23조).
- 시행하는 문서에는 담당자 성명을 표시한다 (책임 제7조④).

**공문서 작성 시 유의사항**
- 나만 이해하는 문서가 아니라 상대가 읽고 이해하기 쉽게 쓴다.
- 애매하거나 과장된 표현을 피하고, 구체적이고 정확한 용어로 간결하게 쓴다.
- 오·탈자가 없게 하고, 날짜·요일·숫자·합계에 착오가 없는지 확인한다.
- "~할 것", "~하기 바람" 같은 위압적인 표현이나 차별적인 표현을 쓰지 않는다.
- 불필요한 외국어, 일반화되지 않은 약어·전문용어를 쓰지 않는다. 꼭 필요하면 괄호에 한자를 쓰거나 용어 해설을 붙인다.

**공문서의 종류**

| 구분 | 종류 | 뜻 |
|---|---|---|
| 유통되지 않는 문서 | 내부결재문서 | 계획 수립, 업무보고 등을 위해 내부에서 결재받는 문서 |
| 유통되는 문서 | 대내문서 | 재단 부서 간 협조·보고·통지를 위해 주고받는 문서 |
| 유통되는 문서 | 대외문서 | 다른 기관, 단체, 국민 등과 주고받는 문서 |

**"끝" 표시**

| 경우 | 표시 방법 |
|---|---|
| 표로 끝날 때 | 표 아래 왼쪽 기본선에서 한 글자(2타) 띄우고 "끝." |
| 본문이나 붙임 표시문이 오른쪽 한계선에서 끝날 때 | 다음 줄 왼쪽 기본선에서 한 글자(2타) 띄우고 "끝." |
| 참고표(※) 문장으로 끝날 때 | 마지막 글자에 온점(.)을 찍고 한 글자(2타) 띄운 뒤 "끝." |
| 별도 송부로 끝날 때 | 괄호를 앞말에 붙여 적음. 예: 붙임  청소년지도사 배치현황 1부(별도 송부).  끝. |

## 7. 작성 예

### 7-1. 대외 발송 문서

```
부천여성청소년재단

수신자  부천시장(아동청소년과장)
(경유)
제  목  청소년수련시설 청소년지도사 배치현황 제출

  1. 부천시 아동청소년과-1234(2026. 6. 15.)호와 관련됩니다.
  2. 재단 소속 청소년수련시설의 청소년지도사 배치현황을 붙임과 같이 제출합니다.

  붙임  청소년지도사 배치현황 1부.  끝.

부천여성청소년재단 대표이사
```

- "~호와 관련입니다."는 어색하다. "~호와 관련됩니다." 또는 "~호와 관련된 문서입니다."로 쓴다.
- 기안자·검토자는 직위로 쓰고, 전결이면 결재란에 "전결"과 날짜를 적는다.
- 결문 주소·전화는 기관 정보로 채운다. 예시에서는 `우 00000 부천시 ○○로 00`으로 표시한다.
