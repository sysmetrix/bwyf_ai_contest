# 4명이 함께 바이브코딩하는 법 (처음 같이 쓰는 사람용)

혼자 GitHub를 쓸 때와 다른 점은 딱 두 가지입니다.

1. **`main`에 바로 올리지 않는다.** 내 브랜치에서 작업하고, PR(합치기 요청)로 올린다.
2. **내 폴더만 고친다.** 남의 폴더를 고쳐야 하면 담당자에게 말한다.

나머지 규칙은 레포의 `AGENTS.md`에 적혀 있어서, Claude·Gemini·Codex·Cursor 같은 AI가 알아서 읽고 따릅니다. 사람이 외울 필요는 없습니다.

---

## 0. 누가 무엇을 맡나

| 사람 | 맡은 일 | 고치는 폴더 |
|---|---|---|
| 영운 | 서무비서 메인 프로그램 구축 (화면·서버·엔진) | `app/` |
| 지은 | 규정·서식 정리본 제작 | `data/` |
| 준호 | 가상 인트라넷 구축 (화면·서버·API) | `intranet/` |
| 원하 | 전체 총괄, 공통 규칙 | `AGENTS.md`, `docs/`, `.github/`, `.githooks/`, `README.md` |

담당이 바뀌면 원하가 이 표와 `AGENTS.md` 2장, `.github/CODEOWNERS`를 함께 고칩니다.

---

## 1. 처음 한 번만

> 터미널이 어렵거나 따로 작업한 파일을 옮겨야 한다면, 아래 2번 대신 [이관요청문.md](이관요청문.md)의 요청문을 AI에 붙여 넣으세요.

1. **초대 수락**: GitHub에서 온 초대 메일을 열거나 https://github.com/sysmetrix/bwyf_ai_contest/invitations 에서 Accept를 누릅니다.
2. **내 PC로 받기** (원하는 폴더에서):
   ```bash
   git clone https://github.com/sysmetrix/bwyf_ai_contest.git
   cd bwyf_ai_contest
   git config core.hooksPath .githooks
   ```
   마지막 줄은 main에 바로 커밋·푸시하면 막아 주는 장치를 켭니다. (이미 클론한 사람도 한 번 실행)
3. **실행해 보기**: `AGENTS.md` 6장 실행 방법대로 메인 프로그램과 인트라넷을 켜 봅니다. (실행 방법은 영운·준호가 정하면 채워집니다)
4. AI 도구로 이 폴더를 엽니다. 첫 대화에서 이렇게 말하세요.
   > 나는 ○○(이름)이고 ○○를 맡았어. AGENTS.md를 읽고 규칙을 요약해 줘.

---

## 2. 매일 이렇게 (AI에게 그대로 말하면 됩니다)

**작업 시작할 때**
> main 최신으로 받고, `내이름/작업이름` 브랜치 만들어서 작업 시작하자.
> (이미 브랜치가 있으면) 내 브랜치로 가서 main 최신 내용 합쳐 줘.

**작업하는 중**
> 평소처럼 원하는 걸 요청. 기능 하나가 되면 "지금까지 내용 커밋해 줘."

**작업 끝낼 때**
> 내 폴더 밖에 바뀐 파일 없는지 확인하고, 브랜치 푸시해서 PR 만들고, 문제없으면 머지해 줘.

---

## 3. PR 합치기 (내 PR은 내가)

리뷰어나 승인을 기다리지 않습니다. **PR을 만든 사람이 직접 확인하고 머지합니다.**

1. 머지하기 전에 아래만 확인합니다. (AI에게 "머지 전에 확인해 줘"라고 하면 됩니다)
   - 내 담당 폴더 밖이 바뀌지 않았나
   - 실명·연락처·문서번호·업체 상호·API 키·원본 파일(PDF·한글)이 들어가지 않았나 (이 레포는 **공개**입니다)
   - (가능하면) 실행해서 화면이 깨지지 않나
2. 괜찮으면 **Merge pull request**를 누릅니다. (AI에게 "머지해 줘"라고 해도 됩니다)
3. 머지하면 브랜치는 자동으로 지워집니다. 다음 작업 때 `main`을 다시 받으면 됩니다.

**예외**: 다른 사람 폴더나 `docs/연동약속.md`를 바꾸는 PR은 머지하기 전에 그 담당자에게 단톡방으로 확인받습니다.

**작게, 자주** 합치는 게 핵심입니다. 이틀치 작업을 한 번에 합치면 충돌이 커집니다. 하루에 최소 한 번은 PR을 올려 주세요.

---

## 4. 충돌(conflict)이 났을 때

같은 파일의 같은 부분을 두 사람이 고치면 생깁니다. 당황하지 말고 AI에게 이렇게 말하세요.

> 충돌 난 부분을 보여 주고, 양쪽 변경이 각각 무슨 뜻인지 설명해 줘. 아직 고치지는 마.

설명을 보고 어느 쪽을 남길지 정합니다. 남의 폴더에서 난 충돌이면 그 담당자에게 물어봅니다.

---

## 5. 다른 파트에 부탁할 때

- 다른 사람 폴더를 바꿔야 하면 GitHub **Issues**에 적고 담당자를 지정합니다.
- 데이터 형식이나 API 주소처럼 두 파트가 함께 쓰는 약속은 `docs/연동약속.md`에 있습니다. 바꾸고 싶으면 먼저 단톡방에서 말해 주세요.
