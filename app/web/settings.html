전자결재 시스템 연결

여기 한 번만 넣으면 서비가 그 시스템의 규정·서식·조직도를 읽어 들이고, 기관 전결표와 맞춰 내 역할을 스스로 판정합니다. 뒤로는 설정할 일이 없습니다.

비밀번호는 설정 파일에 적지 않습니다. 운영체제의 자격 증명 저장소(윈도우 자격 증명 관리자)에 맡깁니다.

메일 알림 연결

서비가 안내 요약과 기한 알림을 담당자 메일로 보내 줘요. 보내기만 하고, 받은 메일은 읽지 않아요.

연결 방법 보기 (처음이면 꼭 읽어 주세요)
  1. 아래 메일 종류에서 쓰는 메일을 고르면 서버 주소·포트가 자동으로 채워져요.
  2. 네이버: 네이버 메일 → 환경설정 → POP3/IMAP 설정 → "IMAP/SMTP 사용"을 사용함으로 저장. 2단계 인증을 쓰면 네이버 → 내정보 → 보안설정 → 애플리케이션 비밀번호를 만들어 그걸 비밀번호에 넣으세요.
  3. Gmail: 구글 계정 → 보안 → 2단계 인증을 켠 뒤, 같은 화면의 앱 비밀번호에서 16자리 비밀번호를 만들어 넣으세요. (평소 구글 비밀번호로는 연결되지 않아요)
  4. 다음·카카오: 다음 메일 → 환경설정 → IMAP/SMTP 사용 켜기. 2단계 인증 중이면 카카오 계정의 앱 비밀번호를 넣으세요.
  5. 기관 메일: 전산 담당자에게 "SMTP 서버 주소와 포트, 외부 프로그램 발송 허용 여부"를 물어보세요. 기관 내부망은 외부 메일 서버가 막혀 있는 경우가 많아요.
  6. 저장한 뒤 테스트 메일 보내기로 확인하세요. 실패하면 이유가 아래에 나와요.
서버 주소·포트 직접 바꾸기

비밀번호는 이 PC 안에만 저장되고 화면에 다시 보여 주지 않아요. 바꿀 때만 새로 입력하세요.

① 지금 PC에서: 내보내기
데이터 파일 내려받기 (.seobi)
② 새 PC에서: 가져오기 새 PC에 서비를 설치한 뒤, 내려받은 .seobi 파일을 고르세요. 가져오기 전에 이 PC의 지금 데이터는 자동으로 백업돼요.
