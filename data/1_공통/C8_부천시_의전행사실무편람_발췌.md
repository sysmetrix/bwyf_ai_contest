# 부천시 의전행사 실무편람 (발췌)

## 1. 용어
- 내빈: 회장·식장 등에 공식으로 초대받아 온 손님
- 의전: 공식 행사나 의식에서 지켜야 할, 공적 성격이 강한 예절 규범

## 2. 원칙
- 인사말씀(축사 등)은 행사 성격에 맞게 운영하되, 원칙적으로 시장, 시의회 의장, 국회의원, 도의회 의장까지 한다.
- 기관·단체별로 묶어 소개할 수 있고, 참석자가 적으면 개별 소개한다.
- 행사 중간에 온 내빈은 마지막에 소개한다.
- 시장, 시의회 의장, 국회의원, 도의회 의장, 정당별 지역(당협)위원장은 개별 소개가 원칙이다.
- 동(洞) 단위 행사는 이 기준을 준용하되 행사 주관 기관장을 먼저, 의원은 해당 지역 의원을 먼저 소개한다.

## 3. 내빈소개 순서

| 순서 | 내빈 | 비고 |
|---|---|---|
| ① | 시장 (대리 참석 시 부시장·국장) | 인사말씀은 부시장까지. 국장이 대리 참석하면 기념사는 하고 인사말씀은 하지 않음 |
| ② | 시의회 의장 | |
| ③ | 국회의원 | 다선 → 연장자 순. 보좌관이 대리 참석하면 소개만 하고 인사말씀은 하지 않음 |
| ④ | 경기도의회 의장 | |
| ⑤ | 관내 대학교 총장 | 가톨릭대 → 서울신대 → 부천대 → 유한대 순 |
| ⑥ | 정당별 지역위원장 | 당협위원장 포함. 지역구, 국회 다수 의석, 선거구 순. 선거 입후보 시에는 후보자 예우에 준함 |
| ⑦ | 도의원 | 다선 → 연장자 → 성명 순. 도 교육위원 포함 |
| ⑧ | 시의원 | 의장 → 부의장 → 위원장(직제 순) → 당 대표 → 의원(다선 → 연장자 순). 세부 순서는 시의회 의장단이 정함 |
| ⑨ | 대리 참석 국회의원 보좌관 | |

**그 밖의 순서 (부천시 의전행사 실무편람)**
민주평화통일자문회의 부천시협의회 회장 → 인천지방법원 부천지원장 → 인천지방검찰청 부천지청장 → 부천교육장 → 경찰서장(원미 → 소사 → 오정 순) → 부천소방서장 → 부천세무서장 → 부천상공회의소 회장 → 통신사 부천지사장 → 부천지사장(국민연금 → 국민건강보험 → 가스안전공사 순)

**그 밖의 순서 (재단 기준)**
- 재단 외부: 청소년·여성 기관장 등 행사 성격에 따른 초청 내빈
- 재단 내부: 이사장 → 이사 → 대표이사 → 관장·센터장(부서 직제 순)

**선거 기간**
- 선거 예비후보자: 지역구 → 국회 다수 의석 → 성명 순
- 선거 후보자: 지역구 → 후보자 기호 순

## 4. 일괄 소개 (2023. 8. 간소화)
- 시 주관 행사에 참여자가 많으면 시·도의원과 기관·단체장을 일괄 소개해 시민 중심의 행사가 되게 한다.
- 일괄 소개할 때는 미리 양해 멘트를 한다.
- 예: "부천시의회 의원님들을 함께 소개해 드리겠습니다. ○○○ 부의장님, ○○○ 위원장님, ○○○ 의원님 참석하셨습니다. 모두 자리에서 일어나 주시기 바랍니다. 일동 경례, 모두 자리에 앉아 주시기 바랍니다."
- 시장·시의장·국회의원·도의장·정당별 지역(당협)위원장은 개별 소개가 원칙이다.
