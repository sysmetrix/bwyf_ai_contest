# 기관 설정서 (v0.5)

> 작성일: 2026-11-05 · 상태: **초안. 확정 대기 항목 없음**
> 용도: 2026 공공 AI 대전환 챌린지 세션2 과제② 서무비서 출품용 데이터의 기준 문서.
> 이후 작성하는 모든 규정·지침·매뉴얼·서식은 이 설정서의 이름·조직·숫자를 따른다.

**v0.5 변경 사항**
- 가상 기관(가온청소년재단·가온시)을 실제 기관명 **재단법인 부천여성청소년재단**과 실제 지명(**부천시** 등)으로 바꿈
- 조직을 규정집 「직제 및 정원 규정」 별표 1 그대로 반영 (여성 분야 시설 포함, 정원 113명 + 수탁기관 20명)
- 표기를 "모의데이터"에서 "서무비서 시연용 정리본"으로 바꿈

**v0.4 변경 사항**
- 행사 운영 설정값 추가. 계획 14일 전, 결과보고 7일 이내는 "권장"으로 표시
- 내빈소개 순서와 외부기관 목록 추가 (12장)

**v0.3 변경 사항**
- 지역 "가온시", 기관명 "가온청소년재단"으로 확정 (v0.5에서 실제 이름으로 변경)
- 여성 분야 시설을 빼고 청소년 시설 4곳으로 재편 (v0.5에서 실제 직제로 변경)
- 위원회 참석수당 초과분 5만원
- 조직 명칭은 2026 규정집 기준
- 일상감사는 구매 업무에 한 줄만 남김

**v0.2 변경 사항**
- 정원 100명으로 조정
- 수치를 실제 업무매뉴얼(2024. 6.)·규정집(2026. 9.) 값으로 교체
- 개인 보충(메모) 층 삭제
- 업무 범위 7개 확정
- 시연 장치 D2 삭제, D3는 원본에 실제로 기록된 개정만 사용

  ├ 부천시여성회관(6)

  └ 수탁기관(20) ─ 부천시건강가정지원센터(5), 고리울청소년센터(9), 부천시일·쉼지원센터(6)

## 4. 결재선·전결 기준 (규정집 「책임 권한 규정 시행세칙」 별표, 매뉴얼 Ⅰ장)

### 4-1. 결재 용어와 순서
- 결재 용어: 검토, 협조, 결재, 전결, 대결
- 결재 순서: 기안자 → 검토자·협조자 → 결재권자
  - 하위 직급에서 상위 직급 순으로 지정한다.
  - 같은 직급이면 소속 부서를 먼저, 타부서를 나중에 둔다.

### 4-2. 복무·출장

| 사무 | 부장 이하 직원 | 실장·관장·센터장 |
|---|---|---|
| 국내 출장명령·복명 | 실장·관장·센터장 | 대표이사 |
| 해외 출장 | 대표이사 | 대표이사 (대표이사 본인은 이사장) |
| 연가·병가 | 실장·관장·센터장 | 대표이사 |
| 조퇴·외출·지참 | 실장·관장·센터장 | 대표이사 |
| 초과·휴일근무 | 실장·관장·센터장 | 대표이사 |

### 4-3. 예산 집행품의 (공사·매입·제조·용역)

| 기준 | 처리 |
|---|---|
| 추정가격(부가세 별도) 건당 **500만원 이하** | 실장·관장·센터장 전결 |
| 추정가격(부가세 별도) 건당 **500만원 초과** (실무상 부가세 포함 550만원 초과) | 대표이사 결재 |
| 추정금액(부가세 포함) **200만원 초과** | 경영지원부장 협조 + 경영지원부 계약 의뢰 |

### 4-4. 외부강의 신고서 결재 (외부강의 지침)

| 신고자 | 결재권자 |
|---|---|
| 1급·2급 | 대표이사 |
| 3~5급 | 실장·관장·센터장 |

## 6. 문서 체계

### 6-1. 위계와 층

| 단계 | 원본 대응 | 번호 표기 |
|---|---|---|
| ① 규정 | 여비 규정, 회계 규정, 책임 권한 규정, 취업 규정, 사무 및 공인 관리 규정, 임직원 행동 강령 | `제○조 제○항 제○호`, `[별표 ○]` |
| ② 시행세칙·지침·기준 | 책임 권한 규정 시행세칙, 공적항공마일리지 시행세칙, 전문가활용경비·국내여비·식간식비 지급기준, 외부강의 등 신고 업무처리 지침 | `제○조`, `[별표]`, `[별지 제○호]` |
| ③ 업무매뉴얼 | 업무매뉴얼 Ⅰ~Ⅳ장 | `Ⅱ-1-1` 식 장절 번호 |
| ④ 서식 | 출장신청서, 연차신청서, 지출결의서, 물품매입품의요구서, 강의확인서, 외부강의등신고서, 공적항공마일리지 신고서 등 | `[별지 제○호서식]` |

**층: 공통 → 기관 → 부서·시설** (개인 보충 층은 두지 않음)
- 공통 층은 상위 법령·범정부 기준이다. 예: 공무원 여비 규정, 청탁금지법, 지방계약법, 시 회계실무 길라잡이, 시 지방보조금 관리기준
- 기관 층은 재단 규정·세칙·지침·매뉴얼이다.
- 부서·시설 층은 시설별 운영규정과 부서별 차이다.

## 7. 시연 장치 (채택: D1, D3, D4, D5, D6)

| ID | 장치 | 원본 근거 |
|---|---|---|
| D1 | **층 간 우선순위**: 같은 물품 구매라도 재원에 따라 기준이 다르다. 재단 사업이면 200만원 이상일 때, 시 보조금사업이면 시 기준에 따라 100만원 이상일 때 비교견적서를 첨부한다. 이 밖에 국외여비는 국가공무원 기준을 준용하고, 자가용 연료비는 「공무원 여비 규정」을 따르는 식으로 기관 규정이 공통 층에 위임하는 사례도 있다 | 매뉴얼 Ⅲ 예산집행품의, 여비 규정 제9조·별표1 비고6 |
| D3 | **규정 개정 (실제 기록분만)**: 회의비 지급단가가 1인 8,000원(2023 신설)에서 15,000원(2024 개정)으로 바뀌었다. 개정 전·후 값과 근거가 원본에 함께 적혀 있다 | 지급기준(2023. 1. 1. 시행), 매뉴얼 Ⅲ-1-5 |
| D4 | **금액 구간별 결재선**: 150만원 구매는 부서장 전결이고 협조가 필요 없다. 300만원 구매는 부서장 전결에 경영지원부 협조와 계약 의뢰, 비교견적 2부가 필요하다. 700만원 구매는 대표이사 결재다 | 시행세칙 별표, 매뉴얼 Ⅰ-1-1 |
| D5 | **직급별 결재권자**: 같은 출장이라도 직원은 센터장이 전결하고, 센터장 본인은 대표이사가 결재한다. 외부강의 신고도 1·2급은 대표이사, 3~5급은 센터장이 결재한다 | 시행세칙 별표, 외부강의 지침 |
| D6 | **기관 설정값 대장**: 8장 표. 다른 기관은 이 값만 바꾸면 된다는 이식성 근거 | — |

※ D3 후보를 더 찾을 때도 원본에 개정 전·후가 모두 적힌 것만 쓴다. 규정집에 `<개정 2023. 12. 18.>` 같은 표시만 있고 개정 전 문구가 없는 경우에는 개정 이력 날짜만 옮긴다.

## 12. 내빈소개 순서 (행사 의전용)

원본(매뉴얼 Ⅳ-1-5, 「부천시 의전행사 실무편람」, 부천시 행정지원과 안내)의 순서를 그대로 쓴다. 인물 이름은 넣지 않는다.

### 12-1. 원칙
- 행사 개요를 참석 예정자에게 미리 공유해 당일 참석 명단을 파악하고, 명단 변동을 챙길 담당자 1명을 지정한다.
- 인사말씀(축사 등)은 원칙적으로 시장, 시의회 의장, 국회의원, 도의회 의장까지만 하고, 행사 성격에 따라 조정한다.
- 행사 중간에 온 내빈은 마지막에 소개한다.
- 참석자가 많으면 기관·단체별로 묶어 일괄 소개할 수 있다. 이때는 미리 양해 멘트를 한다.
- 시장, 시의회 의장, 국회의원, 도의회 의장, 정당별 지역위원장은 일괄 소개하지 않고 개별 소개한다.
- 동(洞) 단위 행사는 이 순서를 준용하되, 행사를 주관하는 기관장과 해당 지역 의원을 먼저 소개한다.

### 12-2. 소개 순서

| 순서 | 내빈 | 비고 |
|---|---|---|
| ① | 부천시장 | 부시장이 대리 참석하면 인사말씀 가능. 국장이 대리 참석하면 기념사는 하되 인사말씀은 하지 않음 |
| ② | 부천시의회 의장 | |
| ③ | 국회의원 | 다선, 연장자 순 |
| ④ | 경기도의회 의장 | |
| ⑤ | 관내 대학교 총장 | 가톨릭대 → 서울신대 → 부천대 → 유한대 순 |
| ⑥ | 정당별 지역위원장 | 당협위원장 포함. 국회 다수 의석 순, 선거구 순 |
| ⑦ | 도의원 | 다선 → 연장자 → 성명 순. 도 교육위원 포함 |
| ⑧ | 시의원 | 의장 → 부의장 → 위원장(직제 순) → 당 대표 → 의원(다선 → 연장자 순) |
| ⑨ | 대리 참석 국회의원 보좌관 | 소개만 하고 인사말씀은 하지 않음 |
| ⑩ | 그 밖의 기관장 | 아래 12-3 순서 |
| ⑪ | 행사 성격에 따른 초청 내빈 | 청소년·여성 기관장 등 |
| ⑫ | 재단 내부 | 이사장 → 이사 → 대표이사 → 관장·센터장(부서 직제 순) |

선거 기간에는 다음 순서로 소개한다.
- 선거 예비후보자: 지역구 → 국회 다수 의석 → 성명 순
- 선거 후보자: 지역구 → 기호 순

### 12-3. 그 밖의 기관장 순서 (「부천시 의전행사 실무편람」 기준)

민주평화통일자문회의 부천시협의회 회장 → 인천지방법원 부천지원장 → 인천지방검찰청 부천지청장 → 부천교육장 → 경찰서장(원미 → 소사 → 오정 순) → 부천소방서장 → 부천세무서장 → 부천상공회의소 회장 → KT 부천지사장 → 부천지사장(국민연금 → 국민건강보험 → 가스안전공사 순)

### 12-4. 일괄 소개 멘트 예시 (2023. 8. 부천시 의전 예우기준 간소화)

- 시 주관행사에 참여자가 많으면 시·도의원과 기관·단체장을 일괄 소개해 시민 중심의 행사가 되도록 한다.
- 개별 소개: "○○○ 도의원님 참석하셨습니다." / "○○○ 원미경찰서장님 참석하셨습니다."
- 일괄 소개: "부천시의회 의원님들을 함께 소개해 드리겠습니다. ○○○ 부의장님, ○○○ 위원장님, ○○○ 의원님 참석하셨습니다. 모두 자리에서 일어나 주시기 바랍니다."

※ 내빈 이름은 언제나 ○○○로 쓰고 실명을 넣지 않는다.
