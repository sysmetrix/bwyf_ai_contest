# 업무별 첨부 서류 목록

> 용도: 서무비서가 기안을 안내할 때 **이번 문서에 무엇을 몇 부, 어떤 순서로 붙여야 하는지** 정확히 알려 주고, 재단이 작성하는 첨부는 서식(F·A)으로 파일을 만들어 주기 위한 목록이다.
> 인트라넷에서는 이 첨부들을 기안문에 **파일로 올린다.** 인트라넷 화면에 첨부 서식 입력 칸을 따로 두지 않는다.

## 0. 읽는 법

### 0-1. 열

| 열 | 뜻 |
|---|---|
| 코드 | 첨부 한 줄의 고유 번호. `묶음코드-번호` |
| 첨부 | 첨부 서류 이름. 기안문 붙임란에 이 이름으로 적는다 |
| 구분 | 누가 마련하는지 (0-2) |
| 필요 | `필수` / `조건` (조건 열에 해당하면 필수) / `선택` (필요하면 붙임) |
| 조건 | 언제 붙이는지. 판단에 쓰는 값은 0-3의 변수 이름으로 적는다 |
| 부수 | 붙일 부수. 비어 있으면 1부 |
| 서식 | 재단 서식 코드. 있으면 서무비서가 그 서식의 `필드:`로 파일을 만들 수 있다 |
| 근거 | 매뉴얼·규정·설정값 ID |

- **표의 순서가 붙임 순서다.** 서무비서는 조건에 맞는 줄만 남기고 위에서부터 `붙임  1. ○○ 1부.`로 번호를 매긴다. 성격이 다른 두 문서를 한 줄에 쓰면 "각 1부"로 쓴다 (M1).
- 지출결의서 묶음은 붙임 순서가 곧 **편철 순서**다 (M4 3-4).

### 0-2. 구분

| 구분 | 뜻 | 서무비서가 할 수 있는 일 |
|---|---|---|
| 작성 | 재단 직원이 서식으로 쓰는 서류 | 서식의 `필드:` 출처에 따라 값을 채운 **파일 초안을 만든다** |
| 결재문서 | 앞서 결재받은 재단 문서 (계획서, 사전 품의서 등) | 인트라넷 결재함에서 해당 문서를 찾아 **문서번호를 알려 주고** 붙이라고 안내 |
| 수령 | 업체·강사·외부기관에게서 받는 서류 | 만들 수 없다. **받을 서류 체크리스트**와 확인할 점을 알려 준다 |
| 출력 | 시스템·누리집에서 뽑는 서류 (카드 영수증, 조회결과 등) | 만들 수 없다. 어디서 뽑는지 알려 준다 |
| 사진 | 직원이 직접 찍는 사진 | 만들 수 없다. 무엇을 찍어야 하는지 알려 준다 |

| 변수 | 뜻 | 값 | 어디서 알 수 있나 |
|---|---|---|---|
| `금액` | 품의는 부가세 포함 추정금액, 지출은 지급액 | 원 | 품의서·지출결의서 합계 |
| `보조금` | 부천시 보조금사업 예산인가 | 예/아니오 | 예산과목(단위사업). 모르면 사용자에게 묻는다 |

| `조달` | 나라장터 종합쇼핑몰에서 사는가 | 예/아니오 | 사용자 입력 |
| `최초거래` | 이 업체와 처음 거래하는가 | 예/아니오 | 사용자 입력 |
| `결제` | 대금을 어떻게 주는가 | 카드/계좌 | 사용자 입력 (카드는 200만원 이하, PUR-04) |
| `1인견적` | 1인 견적 수의계약인가 | 예/아니오 | 계약 방법 (PUR-03) |
| `공문` | 외부기관 관련 공문이 있는가 | 예/아니오 | 사용자 입력 |
| `휴가유형`, `병가누계` | 휴가 종류, 올해 업무 외 병가 누계 일수 | | 근태 기록 |
| `복무처리` | 외부강의 때 복무 처리 | 휴무/출장 | M6 ④ |
| `출강횟수` | 올해·이번 달 외부강의 횟수 | 회 | 신고 기록 (LEC-06) |
| `다회기` | 정기형·다회기 강의인가 | 예/아니오 | 강의 계획 |
| `개인정보수집` | 강사 개인정보를 받는가 | 예/아니오 | 강사비 지급이면 예 |
| `운임`, `숙박비` | 여비 항목 금액 | 원 | A09 여비지급명세서 |

**금액 기준 한곳 모음** (값은 기관설정서 8장이 원본이다. 여기 숫자와 다르면 8장을 따른다)

| 기준 | 값 | 설정값 |
|---|---|---|
| 비교견적 (2개 업체 이상) | `금액 >= 2,000,000`, 보조금이면 `금액 >= 1,000,000` | PUR-02 |

| 중소기업 확인서·직접생산확인서 | `금액 >= 10,000,000` | PUR-05 |
| 정부수입인지 | `금액 > 10,000,000` | PUR-06 |
| 지역개발공채 (1.5%) | `금액 >= 20,000,000` | PUR-06 |
| 계약보증금 지급각서 | `금액 <= 50,000,000` (공사·용역 15%, 물품 10%) | PUR-07 |
| 청구서·강의확인서 도장 날인 | `금액 > 1,000,000` (이하는 서명 가능) | PAY-02 |

## 9. 서무비서 구현 메모 (영운)

1. 업무·단계가 정해지면 해당 묶음을 고르고, 0-3 변수 중 모르는 값만 사용자에게 묻는다. 금액·보조금 여부처럼 기안 화면에 이미 있는 값은 다시 묻지 않는다.
2. 조건에 맞는 줄만 남겨 **붙임 목록(번호·이름·부수)**을 만든다. 이 목록을 기안문 붙임란 문구로 바로 쓸 수 있다.
3. `구분 = 작성`이고 서식이 있는 줄은 그 서식 머리말의 `필드:`에 따라 파일 초안을 만든다. `출처`가 `문서:`이면 앞서 쓴 문서(인트라넷 결재함)의 값을, `설정:`이면 기관설정서 8장 값을 쓴다 (형식은 `data/README.md`).
4. `수령`·`출력`·`사진` 줄은 체크리스트로 보여 주고, 사용자가 파일을 올렸는지 확인만 한다.
5. 인트라넷 기안문에는 이 파일들을 **첨부파일로 올린다.** 서무비서는 상신하지 않는다 (연동약속).
