## 파일 형식

- 모든 파일은 Markdown이며, 맨 위 `---` 사이에 메타데이터(YAML)가 있습니다. 문서코드, 층, 종류, 제정·개정일, 관련 업무, 관련 서식 등이 들어 있습니다.
- 조문은 `**제○조(제목)**` 형식이고, 개정 표시는 `<개정 yyyy. m. d.>`입니다.
- 문서 코드와 업무별 연결은 같은 폴더의 `01_조문지도.md`를 참고하세요.

### 서식 머리말의 `첨부`·`필드` (서무비서가 첨부를 안내하고 파일을 만들 때 씀)

- `첨부:` 본 서식에 붙이는 첨부 **묶음코드** 목록입니다. 예: `첨부: [구매-물품품의]`. 묶음 안의 첨부 줄(무엇을, 조건, 부수, 순서)은 `02_첨부목록.md`에 있습니다.
- `붙는문서:` 첨부서식(A)이 어느 본 서식에 붙는지입니다.
- `필드:` 서식의 칸 목록입니다. 한 줄에 칸 하나를 씁니다.

```yaml
필드:
  - {키: traveler, 이름: 출장자, 형식: text, 출처: "문서:F03.traveler", 필수: true, 안내: "성명은 ○○○"}
```

| 항목 | 뜻 |
|---|---|
| `키` | 칸 이름 (영문). 인트라넷 결재작성 화면에 같은 칸이 있으면 그 키를 그대로 씁니다. 표 안의 열은 `표키[].열이름` |
| `이름` | 서식에 보이는 칸 이름 |
| `형식` | `text`, `textarea`, `date`, `time`, `number`, `money`, `select`, `table`, `image`, `sign` |
| `출처` | 값이 어디서 오는지 (아래) |
| `필수` | `true`면 비워 둘 수 없음 |
| `열`, `선택지`, `안내` | 표의 열 이름, 선택 목록, 작성 안내 |

| 출처 | 뜻 | 예 |
|---|---|---|
| `입력` | 사용자가 씁니다 | |
| `문서:서식코드.키` | 앞서 쓴 문서의 값을 가져옵니다. 표의 열은 `문서:F05.명세[].품명` | `문서:F03.start` |
| `설정:ID` | 기관설정서 8장 설정값 | `설정:TRV-02` |
| `계산:식` | 다른 칸으로 계산합니다 | `계산:end-start+1` |
| `기관:항목` | 기관설정서·로그인 사용자 정보 (부서, 직위 등) | `기관:기안 부서` |
| `고정:값` | 정해진 문구 (바꿀 수 있음) | |
| `오늘`, `시스템`, `목록:묶음코드` | 작성일, 상신 때 시스템이 붙이는 값, 첨부 목록에서 만든 붙임 문구 | |

- 출처 문구 안의 괄호는 사람이 읽는 보충 설명입니다. 서무비서는 앞쪽 `종류:값`만 읽으면 됩니다.
