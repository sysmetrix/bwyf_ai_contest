문서번호: (부서명)-(일련번호)

| 대상자 (부서 / 이름) | 유형 (구분) | 시작일 | 시작시간 | 종료일 | 종료시간 | 신청 일수 | 연차 차감 | 직무대행자 (부서 / 이름) |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

- **유형**: 법정휴가(연차·반차·보건휴가·외출·조퇴·배우자 출산휴가·무급휴가) / 병가·휴직(업무상 병가·업무 외 병가) / 기타(공가·경조사휴가·포상휴가·가족돌봄휴가·대체휴일 등)
- **사유**:
  - 연차·외출·조퇴는 적지 않는다.
  - 그 밖의 휴가는 사유를 적는다.
- **연차 현황**: 기준연도 ____ / 총 연차 ____ / 사용 ____ / 잔여 ____ / 결재 대기 ____

**작성 안내**
- 조퇴·외출은 30분 단위로 신청하며, 하루 4시간을 넘을 수 없다.
- 첨부할 증빙
  - 업무 외 병가가 연 누계 6일을 넘으면 진단서
  - 가족돌봄휴가는 진단서나 가정통신문 (부득이하면 진료확인서)
  - 경조사·공가는 해당 증빙
- 건강검진 공가는 실제 검진일로 신청한다.
