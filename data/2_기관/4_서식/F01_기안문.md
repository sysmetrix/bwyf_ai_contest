## 작성 안내

| 칸 | 작성 방법 | 근거 |
|---|---|---|
| 수신자 | 대외문서는 수신 기관장, 대내문서는 수신자의 직위. (  ) 안에는 처리할 사람의 직위. 수신자가 둘 이상이면 "수신자 참조"라 쓰고 결문에 수신자를 적음. 내부결재문서는 "내부결재" | 사무 제14조 |
| 제목 | 내용을 알 수 있게 간결하게 | |
| 본문 | 항목은 1. → 가. → 1) → 가) → (1) → (가) → ① 순서. 날짜 2026. 11. 5., 시간 15:20 | 사무 제7조·제8조 |
| 붙임 | 하나는 "1부", 성격이 다른 둘 이상은 "각 1부" | M1 |
| 끝 표시 | 본문이나 붙임 끝에 두 타 띄우고 "끝." | 사무 제13조 |
| 발신명의 | 대외문서는 대표이사. 품의서·보고서 등 대내문서는 부서장이나 센터장 직명 | 사무 제15조 |
| 결재란 | 기안자 → 검토자·협조자 → 결재권자. 전결·대결이면 해당 결재란에 "전결"·"대결" 표시 | 사무 제19조·제22조⑤ |
| 시행·접수 | 처리부서명-일련번호와 날짜 | 사무 제12조 |
| 공개구분 | 공개·비공개 선택. 개인정보가 있는 지급 문서(강사비 등)는 비공개(6호) | M7 |
